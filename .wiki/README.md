# Project Knowledge Wiki

An automated, version-controlled **AI Knowledge Wiki** following Andrej Karpathy's LLM Wiki architecture.

## Directory Structure
- **`index.md`**: Central table of contents, topic index, and concept map.
- **`entities/`**: Synthesized knowledge pages covering core modules, data models, APIs, and design patterns.
- **`raw/`**: Unstructured source inputs, raw notes, transcripts, feature drafts, and external documentation dumps.
- **`logs/`**: Audit log of AI curation sessions, additions, and updates.
- **`AGENTS.md`**: Operational rules for AI coding assistants on how to query and maintain this wiki.
